Telegram credentials are NOT stored in any text config file.
Enter them in the app: Settings -> "התראות ו-Telegram" -> Token + Chat ID -> "שמור פרטי Telegram".
They are saved to %APPDATA%\AIStockScannerPro\secrets.json, encrypted with Windows DPAPI (current user only).

Headless / CI alternative (environment variables, take precedence over the file):
    set AISP_TELEGRAM_TOKEN=123456:ABC...        (from @BotFather)
    set AISP_TELEGRAM_CHAT_ID=123456789          (from @userinfobot, or your group id)
